# How to configure basic auth

## Dockerized environment

When running cerebro's docker image the following environment variable must be set.

- `AUTH_TYPE`: must be set to `basic`  
- `BASIC_AUTH_USER`
- `BASIC_AUTH_PWD`

This [docker-compose](./docker-compose.yml) shows how to configure cerebro with basic auth and the user `admin`/`admin`.

`BASIC_AUTH_PWD` may be a plain-text password (hashed at start-up, with a warning) or a bcrypt hash generated by
`cerebro hash-password`. For several users, use the YAML config instead (`auth.basic.users`, see
[docs/CONFIG.md](../../docs/CONFIG.md)).

## Running the binary

```
AUTH_TYPE=basic BASIC_AUTH_USER=admin BASIC_AUTH_PWD=admin ./cerebro
```
